# 🎉 Ganapati Event Management Website

A modern, responsive event management business website built using **HTML, CSS, and JavaScript**.  
Designed for showcasing event decoration services, gallery, and direct customer contact via WhatsApp.

---

## 🌐 Live Website

👉 https://ganapati-event-manager.vercel.app/

---

## ✨ Features

- Responsive modern design
- Hero landing section
- Services showcase
- Image gallery with lightbox
- WhatsApp contact form integration
- Floating call & WhatsApp buttons
- Google Maps location
- Smooth scrolling navigation
- Scroll animations

---

## 📸 Services Included

- Tent Decoration
- Stage Decoration
- Waiter Service
- Photography Service

---

## 📩 Contact Integration

Customers can directly send inquiries via:

- WhatsApp message (form)
- Click-to-call buttons
- Email links

---

- HTML5
- CSS3
- JavaScript
- Font Awesome Icons
